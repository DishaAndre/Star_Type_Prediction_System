🌟 Star Type Prediction System

This project predicts and classifies different types of stars based on their physical characteristics such as temperature, luminosity, radius, magnitude, and age.
It includes data preprocessing, machine learning model implementation, and result visualization.

🔍 Project Overview

Performed Data Preprocessing (handling missing values, duplicates, outliers, and scaling)

Applied Regression, Classification, and Clustering techniques

Conducted Model Comparison and Result Visualization to evaluate performance

⚙️ Tools & Libraries

Python, Google Colab, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

📂 Files Included

Star_Type_Prediction.ipynb – Code notebook

Star_Type_Prediction_Report.pdf – Detailed report

Star_Type_Prediction_Presentation.pdf – Presentation slides
